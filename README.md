# CodePrep – Coding Assessment & Interview Platform

CodePrep is a full-stack web application for coding assessments, practice, and interview preparation.

## Core Modules
- **User Module**: Registration, Login, Logout, Dashboard
- **Coding Assessment Module**: Questions, Assessments, Timer, Scoring, Results
- **Interview Preparation Module**: Technical and HR Questions with Answers/Tips
- **Progress Module**: Assessment History & Performance Summaries
- **Admin Module**: Question & Assessment Management

## Technology Stack
- **Frontend**: React.js (Vite), JavaScript, HTML, CSS, React Router, Axios
- **Backend**: Node.js, Express.js
- **Database**: MySQL
- **Authentication**: JWT, bcryptjs
